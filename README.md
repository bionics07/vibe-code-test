# Meowdoku prototype

A small playable prototype of a cat logic puzzle, inspired by the mobile game Meowdoku. It is a learning project built with AI tools, not a finished or commercial game.

**Play it in the browser:** https://bionics07.github.io/vibe-code-test/

## How to play

Place one cat in each colored region, following three rules:

- One cat per color
- One cat per row and column
- Cats cannot touch, not even diagonally

Tap a cell to mark it with an X, and tap it again to remove the X. Double tap a cell to try to place a cat. A wrong guess leaves a red X and costs one of your three lives.

## About this prototype

- Five levels, with sizes from 4x4 to 8x8
- A demonstration streak screen after level 1, with nothing tracked or saved
- Built with Unity 6.3 for WebGL, with touch and mouse support
- All visuals are generated by code

The level designs and the concept belong to the original game. This project is not affiliated with its creators.
